# D-007 Contract first: generated router, request validation, no internal text in 400s

- **What:** `api/openapi.yaml` is the source; `internal/httpapi` is generated by oapi-codegen; requests are validated by nethttp-middleware + kin-openapi before the router; 400 details carry only the parameter name and the schema reason; `limit*page > 1000` is a 400 from the handler (the vendor caps its result window at 1000, F-003). `servers: [{url: /}]` and `GET /docs/{file}` (enum of the three embedded Swagger UI files) are in the contract so the validator routes them.
- **Why:** one artefact drives docs, validation and handlers; SchemaError text includes the schema and the raw value (review finding).
- **Alternatives:** hand-written handlers with ad hoc checks; absolute servers URL (breaks the router in tests).
- **Consequences:** contract changes need `make generate`; CI checks the generated code builds.
